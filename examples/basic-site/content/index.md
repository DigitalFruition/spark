# A Small Site You Can Copy

This example is shaped like a separate website repository. It depends on `@digitalfruition/spark` and calls the `df-spark` binary from npm scripts.

The layout borrows the classic SitePalette structure: header, top navigation, left navigation, right navigation, page content, footer, and outer wrapper regions.
